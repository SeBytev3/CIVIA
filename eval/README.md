# Evaluación — instrucciones

Crear casos_dorados.json con al menos cinco casos **verificados manualmente** y uno irresoluble con datos existentes. Implementar `evaluar.py` con 15 consultas representativas, P50, P90, error rate, exactitud, coste unitario calculado con tokens/tarifa y trazas; no generar resultados ficticios. Documentar consentimiento de evaluador externo y tres tareas observadas.

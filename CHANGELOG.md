# Cambios de CIVIA

## 1.1.2 · 2026-11-21

- El mapa ciudadano usa el host oficial de OpenStreetMap y envía sólo el origen del sitio como referencia para las teselas. Si no están disponibles, CIVIA ofrece el GPS como alternativa.
- «Abrir cámara» abre una vista previa en la web y la PWA, toma una foto JPEG y libera la cámara al capturar o cerrar. «Seleccionar foto» mantiene la carga desde archivos.
- La guía de instalación incorpora un protocolo para agentes con terminal y Docker. La documentación de Momento 3 añade la ficha de gobernanza, la respuesta a auditorías y los anexos de métricas y seguridad.
- La PWA sigue siendo la entrega móvil. En otro dispositivo, la cámara requiere HTTPS confiable y permiso del navegador.
